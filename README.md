# Site Geada Tattoo

Site responsivo desenvolvido para apresentar a identidade visual, os serviços e as informações de contato da **Geada Tattoo**.

> **Status:** projeto em desenvolvimento. Novas seções, funcionalidades e melhorias serão adicionadas.

## Sobre o projeto

O projeto foi criado para facilitar o contato entre o estúdio e seus clientes, oferecendo uma experiência adaptada para computadores, tablets e dispositivos móveis.

Atualmente, a página reúne informações sobre o estúdio, canais de atendimento, localização, horários de funcionamento e um formulário para solicitação de agendamento.

## Funcionalidades

- Layout responsivo para diferentes tamanhos de tela
- Menu de navegação adaptado para dispositivos móveis
- Banner e apresentação visual do estúdio
- Formulário de solicitação de agendamento
- Validação dos campos obrigatórios do formulário
- Integração com WhatsApp
- Links para Instagram, Facebook e localização no Google Maps
- Informações de contato e horários de funcionamento

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Material Symbols

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/adriano-oliveira-dev/site-geadatattoo.git
   ```

2. Acesse a pasta do projeto.
3. Abra o arquivo `HTML/index.html` em um navegador.

Também é possível utilizar uma extensão de servidor local, como o **Live Server**, no Visual Studio Code.
